Domain Watchdog est un moniteur de noms de domaine basé sur RDAP : il conserve leur historique et aide à les récupérer à expiration.

Les comptes sont locaux à l'app (email + mot de passe) ; aucun LDAP ni SSO n'est proposé en amont. L'accès est protégé par le portail YunoHost. Le premier compte est créé à l'installation pour l'utilisateur admin choisi, avec son email YunoHost et le mot de passe fourni.
