## 📦 Developer info

[![Automatic tests level](https://apps.yunohost.org/badge/cilevel/domain-watchdog)](https://ci-apps.yunohost.org/ci/apps/domain-watchdog/)

🛠️ Upstream Domain Watchdog repository: <https://github.com/maelgangloff/domain-watchdog>

Pull request are welcome and should target the [`testing` branch](https://github.com/YunoHost-Apps/domain-watchdog_ynh/tree/testing).

The `testing` branch can be tested using:
```
# fresh install:
sudo yunohost app install https://github.com/YunoHost-Apps/domain-watchdog_ynh/tree/testing

# upgrade an existing install:
sudo yunohost app upgrade domain-watchdog -u https://github.com/YunoHost-Apps/domain-watchdog_ynh/tree/testing
```

You can also switch to the testing branch to update from testing by default (as same as for APT when you chose to use a testing repos) with this command:
```bash
sudo yunohost app setting domain-watchdog upgrade_channel -v testing
```
